# Granola Email Export: downloads

This page only holds the installers. The app checks here when it opens, and tells you when a new version is ready.

## Install or update

1. Under **Releases** (on the right), open the latest one.
2. Download `GranolaEmailExport-Setup-<version>.exe` and run it. It installs for you only and needs no admin rights.
   Your projects and files are kept when you update.

## If your antivirus warns you

The app is new, so some antivirus tools (for example AVG and Avast) check it before letting it run.
Choose to allow it, or add this folder as an exception:
`%LOCALAPPDATA%\Programs\Granola Email Export`
